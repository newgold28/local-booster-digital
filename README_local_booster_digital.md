## ⚙️ How It Was Built

This project was built using a hybrid AI-assisted workflow:

1. **Lovable AI** — Used to scaffold and generate the initial codebase and UI through AI prompting
2. **Manual Development** — The generated code was then reviewed, customized, and extended with hand-written code to match exact design and functionality requirements
3. **Testing & QA** — The site was fully tested across devices and browsers before deployment to Vercel

> This approach combines the speed of AI code generation with the precision of human development — resulting in a clean, production-ready website delivered faster than traditional builds.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher)
- npm or yarn

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/your-username/local-booster-digital.git

# 2. Navigate into the project folder
cd local-booster-digital

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

Then open your browser and go to: `http://localhost:5173`

### Build for Production

```bash
npm run build
```

Output goes into the `/dist` folder — ready to deploy on Vercel or any static host.

### Preview Production Build

```bash
npm run preview
```
